# 🔐 Password Strength

A lightweight Python CLI tool that evaluates password strength using basic security rules.

## Features

- Checks password length
- Checks uppercase letters
- Checks lowercase letters
- Checks numbers
- Checks special characters
- Does not store passwords

## Run

```bash
python main.py
```

## Scoring

| Score | Meaning |
|------:|---------|
| 1–2 | Weak |
| 3 | Moderate |
| 4 | Good |
| 5 | Strong |

## Built With

- Python
- getpass
- string
